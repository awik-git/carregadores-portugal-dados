# Carregadores Portugal: dados

Cópia compacta dos dados abertos de carregamento elétrico publicados pela **MOBI.E** no Ponto de Acesso Nacional (NAP), em DATEX II:

| Ficheiro | Conteúdo | Atualização |
|---|---|---|
| [`data-chargers/chargers.json`](../../raw/data-chargers/chargers.json) | Postos, tomadas e potências | diária |
| [`data-status/status.json`](../../raw/data-status/status.json) | Disponibilidade em tempo real e preços do operador | ~5 min (dia), ~15 min (noite) |

Fonte: [MOBI.E](https://www.mobie.pt) / NAP Portugal. Este repositório contém apenas o script que transforma os ficheiros públicos e o resultado; não contém dados pessoais nem chaves.
